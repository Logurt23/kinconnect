## Current state

- All work is on branch `claude/kinroot-app` in draft PR #1 (https://github.com/Logurt23/kinconnect/pull/1),
  which merges cleanly into `main` (an empty initial commit).
- All 14 screens are built and tested against local stand-ins: Home (status board, storm mode), Alerts,
  Resources, Requests, Polls, Schedule, Dates, Lists, Groceries, Ledger, Weather, Vault, Family, Settings.
- Stack is all Google Cloud: Cloud Run, Cloud SQL Postgres through a PostgREST sidecar, Identity Platform,
  one private Cloud Storage bucket, Cloud Scheduler, Secret Manager. No Supabase.
- GitHub Actions checks lint, typecheck and build on each push. The browser suite (`e2e/run.sh`) still
  runs only locally, because it needs the local stand-in services.
- It has **never run on real Google Cloud**.
